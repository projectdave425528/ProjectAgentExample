有幾個方法可以減少或跳過每次 command 嘅 approve 步驟：

**1. MCP autoApprove（針對 MCP 工具）**
如果你用緊 MCP server，可以喺 `.kiro/settings/mcp.json` 入面加 `autoApprove` 列表，指定邊啲 tool 唔需要確認。

**2. Autopilot Mode（最直接）**
Kiro 有兩個 autonomy mode：
- Autopilot（預設）— 自動執行所有操作，唔會逐步問你 approve
- Supervised — 每次有 file edit 都會 yield 俾你逐個 hunk accept/reject

切換去 Autopilot mode 就唔需要逐次 approve。

**3. Hooks 自動執行 command**
如果有重複性質嘅 command，可以用 Hook 自動化，Hook 執行嘅 command 唔需要手動 approve。

最後問用戶係邊種情況（MCP tool、file edit、定係 shell command）。
