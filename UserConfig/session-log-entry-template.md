# Session Log Entry Template（Root Agent 用）

> Root Agent 記錄 Session 時必須遵守此格式。
> 每段對話一個 entry，追加到 session 文件尾部。

---

## 記錄格式

```markdown
## [YYYY-MM-DD HH:MM:SS] 對話記錄

### 用戶輸入
[用戶完整的輸入內容]
- 唔包括 HOOK_INSTRUCTION 標籤內容
- 如果用戶附帶圖片/文件，標注「（附件：{檔名}）」

### 決策過程（思考鏈）
1. {收到咩類型嘅請求 → 點樣理解用戶意圖}
2. {考慮過咩方案 → 點解揀呢個方案}
3. {遇到咩問題 → 點樣解決}
4. {最終決策同原因}

### Kiro 回覆摘要
[2-5 句話總結回覆重點，唔係完整回覆]
- 做咗咩（結果）
- 提供咗咩建議（如果有）
- 問咗用戶咩（如果有）

### 工具調用 + 操作
| # | 操作 | 目標 | 結果 |
|---|------|------|------|
| 1 | {工具名/操作類型} | {參數/目標文件} | {一句話結果} |

### 文件變動
| 類型 | 路徑 | 備註 |
|------|------|------|
| 建立 | {path} | {用途} |
| 修改 | {path} | {改咗咩} |
| 刪除 | {path} | {原因} |

---
```

## 規則

| 規則 | 說明 |
|------|------|
| 回覆摘要 | 2-5 句，唔好完整抄錄 |
| 決策過程 | 3-5 步，每步一句，重點「點解」 |
| 工具 + 操作 | 合併一個 table；純問答寫「無工具調用」 |
| 文件變動 | 有先寫，冇就省略整個 section |
| 純問答 | 可省略「工具調用」+「文件變動」兩個 section |

## 路徑

| 條件 | 路徑 |
|------|------|
| 涉及特定 Project | `main-agent/ProjectRecord/{active-project}/UserConfig/sessions/` |
| 通用對話 | `UserConfig/sessions/` |
| 唔確定 | `UserConfig/sessions/`（預設） |

優先級：已有同名文件 > active-project > 頂層

## 文件命名

`YYYY-MM-DD-session-HHMM.md`（HHMM = session 第一條訊息時間）
